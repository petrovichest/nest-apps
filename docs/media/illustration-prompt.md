# Architecture illustration prompt

Created with the built-in `imagegen` tool. The input reference was the reviewed
four-client composition; the exact final edit prompt is below. The selected output
is stored as `architecture-illustration.png`. Image generation is not part of the
repeatable capture command: captions, the existing CON mark and the real Onest font
are composed separately by the HTML templates.

```text
Use case: precise-object-edit.
Asset type: reusable central illustration for the CodexNest README infographic and cover.
Input image 1 is the approved composition and the edit target.

Keep the same visual idea and recognizable minimalist device silhouettes: one HEADLESS host in the middle, laptop upper left, tablet upper right, Android phone lower left, another browser phone lower right. Preserve the four thin curved connections between the host and these four client examples. Preserve the same sparse shared conversation motif on every client screen.

Make these changes:
1. Remove ALL typography, captions, brand word, headings, footnotes, infinity symbol and its vertical dots. We will typeset labels separately using the real Onest font. There must be NO letters, words, numbers, logos, icons resembling letters, or infinity symbol anywhere in this artwork.
2. Remove ALL decorative green/sage/olive. The palette is strictly neutral graphite and almost-white: opaque white canvas #ffffff; light surfaces #f8f9f6; dark outlines #292a29; small accent marks #20211f; curved links and minor details #6a6c67. Every connection, endpoint dot, small device status dot and screen message motif MUST be neutral charcoal/gray, never green. No colored shadows, blue tint or warm beige tint.
3. Reframe to a wide illustration, around 2.3:1 aspect ratio. Crop away the large empty former heading/footer areas. Give the four clients breathing room around the central host. Keep empty white space immediately below each device and below the host for later labels. The upper two clients and lower two clients should be clearly separated vertically.
4. Simplify the server to two small soft rounded horizontal slabs, frontal view, with one tiny neutral status dot and short slot each, minimal depth and gentle shadow. It is a HEADLESS symbol: absolutely NO monitor, screen, desktop UI, keyboard, tower, complicated chassis or server rack. The central host is visually compact; it must not dominate the other devices.
5. Keep gentle ambient shadows, crisp minimalist outlines and soft silhouettes. Flatten excessive extrusion. No realistic materials, glass, glossy hardware, colored gradients, dramatic lighting or heavy cast shadows.

Composition and accuracy constraints:
Exactly ONE central host symbol consisting of two stacked slabs, exactly FOUR client devices. Each device connects directly to this host through one quiet neutral curved line. No extra cloud, accounts, people, arrows, objects, frames around groups, or separate boxes. Client screens can contain only identical abstract light-gray message strokes and a tiny neutral progress circle.
Final canvas must be a FULLY OPAQUE pure-white rectangle, no transparent pixels anywhere, no transparent background extraction. This is a white-page illustration.
Keep every object fully inside the canvas with comfortable margins. No text, watermark or added decoration.
```
